# Girlz Platform 💜

A full-stack social media platform designed for women, featuring modern web and mobile applications.

## 🌟 Features

### Authentication & Security
- Sign up, login, password management
- Two-factor authentication (2FA)
- Passkeys support
- OAuth (Google, Apple)
- Teen protection

### Social Features
- **Profiles**: Customizable profiles with verification
- **Feed**: Posts, photos, videos, carousels, smart recommendations
- **Reels**: Video creation, editing, effects, remixing
- **Stories**: With stickers, music, and highlights
- **Messaging**: DMs, groups, voice, video calls, GIFs
- **Discovery**: Search, explore, hashtags, locations
- **Social Interactions**: Likes, comments, shares, saves, reposts, collabs

### Creator Tools
- Creator dashboard with analytics
- Monetization features
- Brand collaboration tools
- Live streaming with guests
- Content moderation

### Business Features
- Advertising platform
- Shopping integration
- Product showcase
- Promotions

### AI & Intelligence
- Smart recommendations
- AI-powered content creation
- Intelligent editing
- Translation support
- Content moderation

### Safety & Privacy
- Comprehensive reporting system
- User blocking
- Privacy controls
- Security features
- Teen protection features

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- PostgreSQL 14+
- Redis 7+

### Installation

```bash
git clone https://github.com/Gurans-07/girlz-platform.git
cd girlz-platform

npm install

cp .env.example .env.local

npm run dev
```
