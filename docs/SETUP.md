# Setup Guide

## Prerequisites
- Node.js 18+
- PostgreSQL 14+
- Redis 7+

## Local Development Setup

### 1. Clone Repository
```bash
git clone https://github.com/Gurans-07/girlz-platform.git
cd girlz-platform
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Setup Environment
```bash
cp .env.example .env.local
```

### 4. Start Development Servers
```bash
npm run dev
```

Services will be available at:
- Backend API: http://localhost:3000
- Frontend: http://localhost:3001
